📖 Como usar o Sistema de Cartão Ponto

👤 1. Adicionar funcionários

  • Digite o nome no campo e clique "+ Adicionar Funcionário" ou pressione Enter
  • Clique no cabeçalho do card para expandir ou recolher
  • Use "↕ Expandir Todos" / "↑ Recolher Todos" para controlar todos de uma vez

⏰ 2. Digitar horários

  • Clique no campo e digite 4 dígitos — o sistema formata automaticamente: 0700 → 07:00
  • Pressione Enter ou Tab para confirmar e avançar
  • Campo vazio + Enter: copia o horário da mesma coluna do dia anterior
  • Ordem de navegação: Entrada → Saída do dia → Entrada do próximo dia útil…
  • Fins de semana e dias inativos são pulados automaticamente
  • Os campos de intervalo são preenchidos automaticamente com o horário configurado

⌨️ 3. Teclado

  • Enter ou Tab → próximo campo (Entrada → Saída → dia seguinte)
  • Shift+Tab → campo anterior
  • Campo vazio + Enter → copia do dia anterior

🎨 4. Cores

Entrada amarela:  chegou mais de 5 min atrasado
Saída vermelha:  saiu mais de 5 min antes
Saída azul:  30+ min além do horário
Linha verde:  saldo positivo no dia
Linha vermelha:  saldo negativo no dia

⚙️ 5. Configurar horários

  • Clique em "⚙️ Configurar Horários de Trabalho"
  • Padrão: Seg–Qui 07:00–17:30 e Sex 07:00–16:30 (intervalo 11:30–13:00)
  • Ative/desative dias e edite os horários; clique "✓ Salvar Configuração"

💾 6. Dados e exportação

  • Tudo é salvo automaticamente no navegador (localStorage)
  • 📤 Exportar Banco de Dados → arquivo .json com todos os dados
  • 📥 Importar Banco de Dados → restaura de um .json anterior
  • ⬇ Exportar Excel → planilha .xlsx no formato padrão da empresa
